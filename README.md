# Python Scan vs Nmap Report

## Objective
This mini task compares a basic Python port scanner with an Nmap scan.

## Python Port Scanner
- Written in Python using socket library
- Scans selected ports
- Displays open and closed ports

## Nmap Scan
- Professional network scanning tool
- Detects open ports and services
- Faster and more accurate than Python script

## Conclusion
Python scanning helps understand networking basics,
while Nmap is used for professional security assessment.
